# VoiceToNotes.ai – Manual QA Testing Project

## Project Overview
This project demonstrates practical manual software testing of the VoiceToNotes.ai web application, focusing on functionality, usability, authentication, defect identification and regression testing.

## Testing Objectives
- Identify and document application defects.
- Verify expected and actual application behavior.
- Validate user authentication and dashboard functionality.
- Evaluate core voice recording and transcription workflows.

- Novel links displaying 404 errors.
- Novel page displaying a "Novel Not Found" message.
- Inconsistent novel thumbnail and title.
- Unresponsive email verification link.
- Mobile compatibility observation during Google login.

Some findings require further investigation and confirmation of product requirements.
